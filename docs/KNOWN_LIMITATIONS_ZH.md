# 已知限制与下一阶段

本轮交接整理固定源码和配置、统一现有五类短引用读取配套、提供三条离线示例并核对安装。它没有承诺所有自然语言业务已经稳定识别。

| 未完成项 | 当前边界 | 后续应怎样处理 |
|---|---|---|
| LLM 首读仍会误读 | 背景、政策、信息状态和引用偶有错误；独立审核继续阻断 | 另做冻结新业务的首答 / 复查验收，本轮暂不继续调 Prompt |
| 数学库比共同业务入口更广 | 原生 R1a/R1b/R2/R3、D1–D6、E1–E5 不是任意组合都已从自然语言接通；均值顺序主要使用专门研究入口 | 依照能力合同逐一接入，不把读取登记等同于新增数学覆盖 |
| PARTIAL 范围有限 | 有限均值模型及明确总体信息、界和完整性条件；sharp 仅相对于已审模型 | 新子域须补严谨合同、推导和独立验证，不能机械套用其他界 |
| 全新方法与库外研究 | IV、一般图识别、网络与 DAG 联合模型未形成完整公共合同；候选研究仍是独立受控路径 | 新方法先数学审核，LLM 候选保持 `LLM_UNVERIFIED`，不自动进入正式结果 |
| 兼容布局与协议仍存在 | Core 分布于原网络包与 `cfm_id`；旧 hash 来源 DAG、旧读取配置和早期原型保留 | 学生只用推荐入口。后续有实际改动需要再迁移，不任意更改旧绑定 |
| 尚非无审核生产产品 | 审核身份签名、跨副本撤销、完整多人协作界面尚未实现 | 哈希仅校验内容，不证明身份或科学条件为真 |
| 研究证据与泛化 | 离线夹具、合成审核和现有真实 API 样本不构成独立盲评；文献映射也非完整系统综述 | 扩展前核对文献实际支持范围，单独报告自然语言准确率 |

本次未改数学 Core、Prompt 或 Estimation / Policy，未调用付费 API，未提交 Git。最终实际测试与安装记录见[交接验收](DELIVERY_READINESS_ZH.md)。

接手后先运行三个示例、阅读代码地图与扩展规则；不要先选更大的协议版本号。工程起点与数学安全边界明确后，再按业务价值增加能力或安排独立读取评测。
