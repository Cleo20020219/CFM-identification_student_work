## 普通业务怎样进入

原始问题和材料 → `project.start` / `business_intake` 的 A0 → 逐字段意图与来源审核 → `business_dispatch` 的专门事实读取 → A4 信息、A5 科学条件及目标绑定审核 → 当前数学方法 → 独立证书重放。`business_case` 汇总所有子问，不能用一个子问成功代表整题完成。

用户不选 R1a/R2、POINT/PARTIAL 或内部会话。能力分派中的五个事实家族由审核后的研究结构、目标和必要的观测／实验类别选择；登记本身不判断科学条件成立，也不授予求解许可。可执行登记以 `cfm_id.capability_registry.inventory()` 为准。组件配对是另一职责：`cfm_id_llm.fact_reading_contracts` 已收拢上述五类 short_refs 家族；旧 hash 来源 DAG 保留兼容适配。

| 共同入口已连接的目标 | 已连接的方法 | 必须保持的范围 |
|---|---|---|
| 一个完整固定政策的均值 | R1b、R2；有限政策均值界 | 完整政策、评价对象与聚合明确；方法自己的网络、设计、暴露和信息合同逐项检查 |
| 观察性、固定处理前 W 下一个完整政策的均值 | R3_FULL_ASSIGNMENT；显式签名读取配置可用R3_MEAN_SIGNATURE | 明确完整观测总体律和逐对象条件均值、独立交换性等审核；最多12个对象；签名路线另审全安排条件均值充分性与覆盖范围，正支持由原生后端检查；已有小批真实验收，首读仍不稳定 |
| 两个完整固定政策的第一端减第二端 | R1b／R2 的有向组合；有限联合差值界 | 同一人群、结果及背景；联合求界不能用两个独立区间机械相减替代 |

| 局部直接效应、同伴效应 | R1a 组合；直接效应两个方向均已连接 | 已连接 D1–D6/E1–E5 的既有合同；固定评价名单；每端按原设计条件概率平均；不能擅自改成某张完整名单或其他分配规则 |
| 变量 DAG 的干预分布 | 经典后门、调整、单变量经典前门 | 保留各自图、变量角色、信息与验证合同；不与对象合作网络自动合并 |

## 原生能力与未完成扩展

网络 R1a/R1b/R2/R3、D1–D6、E1–E5 分别是识别机制、分配设计、暴露定义；不是互斥的业务类别。已有 D1–D6/E1–E5 已连接局部直接/同伴效应、固定政策均值和两政策差值；具体参数、正支持和科学条件仍逐项检查，不保证任意组合实例都可点识别。接入及验收范围见[设计与暴露入口](NETWORK_DESIGN_EXPOSURE_ENTRY_ZH.md)。D2/E1均值顺序两政策差值已接共同入口，复用逐轴审核和原证书重放，见[接入说明](NETWORK_MEAN_ORDER_ENTRY_ZH.md)。R3 其他目标仍有专门接口，不能算作全部接通。

库外 LLM 建议仍走受控研究路径，标为 `LLM_UNVERIFIED`；尚无统一自动后续步骤，更没有任意新证明的万能验证器。IV、一般图识别、新的 PARTIAL 模型、网络与 DAG 联合模型，以及真实多人协作的身份认证和签名不属于本轮收尾。Estimation/Policy 不改动。

## 哪些停止不是数学结论

| 情况 | 处理要求 |
|---|---|
| 读错、字段归属或引用不足 | 定位原文后显式重读，全部变更重新审核；不直接清洗模型回答 |
| 原文确实缺条件、尚未决定或有冲突 | 保留缺项并追问；补充材料后旧审核失效 |
| 审核拒绝、请求或证据错配 | 阻断；不得调用数学后端 |
| 真实额外条件或目标不在当前适配范围 | 报告未覆盖／未接通，不宣称已证明不可识别 |
| 已求解并独立重放 | 按证书报告 POINT、有限 PARTIAL 或对应数学结论与适用范围 |

样本均值不因表格完整就变成已知总体均值。某项信息在其他字段中重复出现，不能替代它所属字段的完整值与实际来源；真实的上界、单调关系或具体数值也不能为了获得 POINT 而删除。

本轮之后暂停逐条增加 Prompt/Skill 防御语句，保留一个冻结的局部实验配置。只有接口矛盾、来源绑定错误、审核可被绕过或数学错误属于必须立即修复的问题；孤立的模型漏读先保留原始失败、显式复查与独立审核，不扩大调用循环。
